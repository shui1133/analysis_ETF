## ⚠️ 重要注意事項

### 1. 路徑變更

**Windows 用戶：**
- 新路徑：`C:\Python\退休理財規劃分析\data`
- 系統會自動建立
- 舊資料需要手動遷移

**Linux/Mac 用戶：**
- 新路徑：`/data`（根目錄）
- 可能需要 sudo 權限

**解決權限問題：**
```bash
# Linux/Mac
sudo mkdir /data
sudo chown $USER:$USER /data

# 或修改程式碼使用其他路徑
```

### 2. 爬蟲使用限制

**MoneyDJ：**
- ⚠️ 建議間隔 1-2 秒
- ⚠️ 避免大量連續請求

**Goodinfo：**
- ⚠️ **必須**間隔 2-3 秒以上
- ⚠️ 嚴格反爬蟲機制
- ⚠️ 過度使用可能封 IP

**建議：**
- 優先使用 yfinance
- 僅在必要時使用其他來源

### 3. 資料準確性

- ✅ 建議驗證重要配息資料
- ✅ 比較多個來源
- ✅ 使用官方資料作最終確認
